What the cursors do

Every piece gets the tool a designer would use.

The scanner reads your real DOM and plans a job for each piece. Watch the cursor change shape as it switches tools.

Boxes

A crosshair drags from the corner with handles and a live size badge.

Borders

The pen clicks each corner, leaving vertex dots along the path.

Text

The I-beam types like a person: bursts, little pauses, key clicks.

Guides

Rulers slide in, a guide is dragged out and text snaps onto it.

Repeats

The first card is built, then alt-dragged into copies with spacing.

Images

A placeholder is dragged out, then the real image fades in with a chord.

How it works

It builds what you are looking at.

Scroll slowly and a few cursors work through the page with you. Fling the page and the swarm floods in to catch up, and every cursor picks up the pace.

01 / measure

Only what is near the screen is scanned.

Sections start as they approach. Nothing below the fold is hidden up front.

02 / plan

Parents first, then children, top to bottom.

Repeated cards become duplicates, aligned text gets a guide to snap onto.

03 / perform

The real page is uncovered, never a copy.

A failsafe always reveals everything, so readers and crawlers never miss a word.

Get started

One line for the whole show.

Call it on a page, a single section, or as a transition between views.

  • Typed config with presets: calm, default, frenzy
  • Respects reduced motion out of the box
  • Optional glass-piano soundtrack, all synthesized
import { curchestra } from 'curchestra';

// a ring of cursors circles your logo,
// the first scroll sends them off to build
curchestra({ sound: true })
  .page({ trigger: 'scroll', intro: '#logo' });

// or just one section, as it comes into view
curchestra().section('#features');
